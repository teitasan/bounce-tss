# クラフト甲羅（プロトタイプ）

甲羅を投げ合い、壁で跳ね返して当てる 2D トップダウンの対戦ゲーム。（開発中の作業名は「反射弾TSS」）画面上部のボタンで5つのモードを切り替える（選んだモードはブラウザに保存。初めて開いたときはカスタム甲羅）。

- **ローグライク**: 雑魚を倒して弾を育てる。ローカル・シングルプレイ
- **甲羅バトル**: 元のコンセプト「マリオカートの緑甲羅を投げ合う」の検証用。最終目標は人間同士の対戦で、今は CPU 3体を相手にする
- **カード甲羅**: 甲羅バトルにデッキを足したもの。ラウンドの合間に甲羅の種類を入れ替えてデッキを育てる
- **カスタム甲羅**: 甲羅は常に3つ。ラウンドの合間に効果を付けて、3つの甲羅それぞれを育てる
- **クラフト**: カスタム甲羅のドラフトの代わりに、試合中に箱を壊して拾った素材が甲羅に入り、2つ揃うと効果になる（お試し。ひとりで CPU と）

```bash
cd tss
npm install
npm run dev   # http://localhost:5173（ゲームと対戦用の部屋サーバーが1つの Vite で同時に動く）
```

### デプロイ（Cloudflare Workers + Durable Objects）

```bash
npx wrangler login
npm run deploy
```

wrangler は Node.js 22 以上が必要。この開発機の既定は Node 20 なので `mise exec node@25.9.0 -- npm run deploy` で実行する（あいさつシューターと同じ）。

## ローグライクの操作

- WASD 移動 / マウス 照準 / 左クリック または Space（長押しで連射）射撃
- Esc ポーズ / Tab デバッグパネル / 死亡後 R でリスタート
- レベルアップ時はクリックか 1・2・3 キーで選択

## 甲羅バトル（`src/shell/`）

### 操作

WASD 移動 / マウス 照準 / 左クリック・Space 甲羅を投げる / Esc ポーズ / R 次のラウンド（自分が脱落した後も可）

マウスの固定：試合中（カウントダウン中も）にゲーム画面をクリックすると、マウスを画面内に固定する（ブラウザのポインターロック）。カーソルは消え、照準はマウスを動かした分だけ動き、試合場の内側から出ない。Esc で固定が外れ、そのままポーズする。結果・ドラフト・ロビー・デバッグなどマウスで押す画面が出たときは、ゲームが自動で外す（このときはポーズしない）。アプリ内のプレビューのように固定が許されない環境では、今までどおりカーソルで狙う

### ルール

- 4人のバトルロイヤル。HP3、最後の1人が勝ち。勝利数をラウンドをまたいで数える
- 手持ちの甲羅（最大2個）は自分の周りを回る（マリオカート方式）。投げると1個減り、2.5秒ごとに1個戻る
- 周回している甲羅にも当たり判定がある
  - 飛んできた甲羅に当たると両方割れる（盾）。重甲羅が周回しているときは相手の甲羅だけが割れ、貫通甲羅は1回だけ抜けてくる
  - 相手の体に当たると、相手にダメージを与えて自分の周回甲羅が割れる（体当たり）
  - 周回甲羅同士がぶつかると両方割れる
  - 投げてから0.3秒は、投げた甲羅が自分の周回甲羅を通り抜ける
- 盾は確実ではない。真横から飛んできた甲羅を止められた割合は、手持ち1個で約15%、2個で約35%（周回の位置しだい）
- ノーマル甲羅は外壁と柱で反射し、4回を超えて反射するか6秒たつと割れる（最後の1.5秒は点滅）
- 甲羅は誰にでも当たる。自分の甲羅も、投げてから0.3秒たつと自分に当たる
- 甲羅同士がぶつかると両方割れる（撃ち落とせる）
- キャラが甲羅に当たる判定は半径11で、見た目（半径14）より少し小さい（かすっても当たらない。`SHELL.hurtRadius`）
- 被弾するとノックバックし、1.2秒無敵
- 軌道ガイドは出さない。飛んでいる甲羅には残像が付く（`ShellScene.ts` の `TRAIL_LENGTH`）

### 見た目と演出（甲羅バトル・カード甲羅・カスタム甲羅で共通）

- 見た目は最初のシンプルな形（2026-10-15、サイバー調・ピザ屋・SFC 風を試した後に戻した）：マス目のある暗い床、灰色がかった青の壁と柱、甲羅は色の円に白い縁（分裂前は「V」、反発が残っていれば外側に輪、中心に投げた人の色）、キャラは色の円と照準の線。左上に文字のプレイヤー一覧、画面下に手札、ラウンド開始は画面中央の 3・2・1（1.5秒）
- 被弾すると一瞬時間が止まる（自分は0.11秒、CPU は0.05秒、脱落は0.14秒）
- リプレイ：脱落の1.7秒前から0.4秒後までを、0.7倍速（約3秒）で拡大して流す。カメラはやられた側と当てた側の両方が入るように追いかけ、2人が近いほど大きく寄る（1.1〜2.1倍、自滅なら1人だけ）。「REPLAY」表示。R かクリックで飛ばせる。直近4秒ぶんを常に録画している（`ShellScene.ts` の `REPLAY`）。スロー再生は録画のコマの間を補間してなめらかにする（キャラ・周回甲羅・飛んでいる甲羅・粒子）
- 描画の解像度：Retina などの高精細な画面では2倍の解像度で描き、輪郭をなめらかにする（`config.ts` の `PIXEL`）
  - 自分が脱落したとき：0.4秒後に、やられた場面を流す。裏では試合が進み続ける（人間同士の対戦で、やられた人だけが見る形を想定）
  - 決着したとき：最後の脱落を流す。自分の脱落で決着した場合や、自分のリプレイ中に決着した場合は、自分のリプレイだけを流す
- リプレイの後、勝者にカメラが寄ってスローモーションになり、0.8秒後に結果を出す
- ドラフトでは CPU が0.55秒ずつ順番に選ぶ。候補を選ぶと、付けた後の甲羅の効果が先に見える
- 試した見た目の部品は残してある：効果ごとの模様（`src/shell/visuals.ts`）、ピザ（`src/shell/pizza.ts`、デバッグウィンドウの「ピザで表示」）

### CPU

- 一番近い相手に対して、適度な距離を保って横に回り込む
- 0.7秒先までに自分の近くを通る甲羅があれば、その進路から横へ逃げる
- 投げるときは96方向の軌道を試し、反射込みで一番早く相手に届く角度を選ぶ（自分に跳ね返る角度は避ける）。照準には少しぶれがある
- 投げる間隔は1.5〜3秒（`SHELL.botThrowInterval`）
- 周回甲羅を入れた後、カード甲羅で CPU 3体だけで5ラウンド回すと1ラウンド34〜63秒、3人が残っている間のフィールドの甲羅は平均5.0個（分裂の子を含む）

### 数値

`src/shell/ShellScene.ts` の `SHELL`（甲羅の速さ・大きさ・寿命・反射回数・同時数・無敵時間など）と、`src/shell/arena.ts` の `PILLARS`（柱の配置）。

## カード甲羅（`src/shell/cards.ts`）

甲羅バトルと同じルールで、甲羅の種類が順番に変わる。デッキはラウンドの合間に育てる（ドラフト）。

### 試合とドラフト

- デッキはノーマル甲羅6枚から始まり、枚数は試合中ずっと6枚のまま。先に5勝した人が優勝。優勝が決まると全員のデッキと勝利数が初期状態に戻る
- 各ラウンドの後、プレイヤー数ぶん（4枚）の候補をランダムに並べ、脱落した順に選ぶ（最後まで残った勝者が最後）
- 自分の番では「候補1枚とデッキの1枚を交換」か「交換しない」を選ぶ。前の人が取った候補は選べない
  - 1・2・3・4 キーかクリックで候補を選び、続けてデッキの中の入れ替えるカードをクリック
  - N キーか「交換しない」ボタンで交換しない
- 自分より前の CPU が何を取ったかは画面に出る
- 全員のデッキの中身は左上の色の並びで見える
- CPU は、デッキにノーマル甲羅があれば残っている候補からランダムに取ってノーマル甲羅と入れ替える。ノーマル甲羅がなければ、半々で交換しないか、一番多い種類と入れ替える
- 自分が脱落した後は R で4倍速の早送り（勝敗がドラフトに関わるので、ラウンドは飛ばせない）

### 甲羅の出方


- テトリス方式：投げられるのは「今」の甲羅だけで、次に来る甲羅が3個見える（画面下）。投げるとすぐ次の甲羅になる
- 自分のデッキをシャッフルして順に出し、尽きたらまたシャッフルする
- 周回している手持ちの甲羅が「今」と「次」の甲羅になる（色と大きさで分かる）。同じ1投から出た親子の甲羅は互いにぶつからない
- `cards.ts` の `CARD_RULE.pick` を `true` にすると手札方式に戻る（手札3枚から 1・2・3・Q・E・ホイールで選び、使ったカードは0.6秒で補充）

速さは `cards.ts` の `SPEED_SCALE`（0.8）をかけた後の値。

| 甲羅 | 速さ | 大きさ | 反射 | 寿命 | 特徴 |
| --- | --- | --- | --- | --- | --- |
| ノーマル甲羅 | 320 | 9 | 4回 | 6秒 | 標準 |
| 跳ね甲羅 | 240 | 8 | 9回 | 9秒 | 遅いが長く残る |
| 分裂甲羅 | 304 | 9 | 3回 | 6秒 | 最初の反射で、跳ね返った方向の左右（±29°）に子甲羅を1つずつ飛ばす。親はそのまま普通に反射して進む。子は小さく明るい色で、1回反射・3秒。分裂前は「V」の印、分裂時に輪が広がる |
| 追尾甲羅 | 272 | 9 | 3回 | 6秒 | 投げた瞬間から、投げた人以外の一番近いキャラへ曲がる。相手まで110px以内に近づくと、その後は曲がらない |
| 重甲羅 | 208 | 15 | 2回 | 6秒 | 甲羅同士でぶつかると相手だけ割る。当たったときのノックバックが1.6倍 |
| 3連甲羅 | 256 | 7 | 2回 | 5秒 | 3方向（約16°間隔）に同時に投げる。手持ちは1個しか減らない（ローグライクの弾数増加） |

| 貫通甲羅 | 288 | 9 | 3回 | 6秒 | 甲羅や周回甲羅に1回当たっても割れずに抜ける（貫通） |
| 加速甲羅 | 208 | 9 | 4回 | 7秒 | 反射するたびに1.2倍速くなる。最大で元の2倍（反射チャージ） |

CPU は今の甲羅で当たる角度があれば投げる。追尾甲羅だけは、当たる角度がなくても相手の方へ投げる（手札方式のときは、直接当てられるなら重甲羅・ノーマル甲羅、反射が必要なら分裂・跳ね甲羅、角度がなければ追尾甲羅を優先して選ぶ）。CPU 3体だけで5ラウンド回すと1ラウンド34〜54秒だった。

## カスタム甲羅（`src/shell/custom.ts`）

甲羅バトルと同じルールで、甲羅は常に3つ（甲羅1〜3）。試合開始時は甲羅2だけ追尾1、甲羅1・3はノーマル甲羅と同じで、ラウンドの合間に効果を付けて育てる。試合の流れ（先に5勝、脱落した順に選ぶ）はカード甲羅と同じ。

- 3つの甲羅が自分の周りを回り、甲羅ごとに補充される（投げた甲羅、または周回中に割れた甲羅だけが2.5秒の補充待ちになる）
- 投げる順番は最初 1→2→3、3つ投げ終えるたびにシャッフル。順番の来た甲羅が補充中なら、手元にある甲羅のうち順番が一番早いものを投げる
- 画面下に3つの甲羅が投げる順に並び、付いている効果が出る。甲羅の色は一番レベルの高い効果の色
- ドラフト：プレイヤー数ぶん（4つ）の効果を、11種類からランダムに候補に並べ、脱落した順に「効果を1つ取って甲羅1〜3のどれかに付ける」か「付けない」を選ぶ。同じ効果を重ねるとレベルが上がる（上限なし）
- 左上に全員の甲羅3つの色が出る（マウスを乗せると効果の一覧）
- ドラフト画面は四隅にプレイヤー1〜4（左上・右上・左下・右下）の枠を並べ、それぞれの甲羅3つと付いている効果、勝ち数の星、選ぶ順番（選んでいる人の枠は光る）を出す。効果を付けた甲羅は一瞬光る。真ん中に候補と自分の甲羅を選ぶ画面。画面の幅が960px 未満では、真ん中の画面の下にプレイヤーの枠を2列で並べる（カード甲羅はデッキの一覧）
- CPU は残っている候補からランダムに取り、半分は同じ効果を持つ甲羅に重ね、残りはランダムな甲羅に付ける
- Tab でデバッグウィンドウ：自分の甲羅1〜3に効果を＋／−で好きなだけ積める（すぐ反映。投げた後の甲羅は変わらない）。「自分は無敵」「CPU が投げない」「当たり判定を表示」（赤＝キャラが甲羅に当たる判定、灰＝キャラの見た目、黄＝甲羅）の切り替えと、試合開始時の状態に戻す「全部リセット」付き

| 効果 | 1レベルごとの効果 |
| --- | --- |
| 追尾 | 投げた瞬間から、投げた人以外の一番近いキャラへ曲がる。相手まで110px以内に近づくと、その後は曲がらない。曲がる力はレベルと同じ（1 / 2 / 3 … rad/秒） |
| 分裂 | 最初の n 回の反射で、左右に子甲羅を1つずつ飛ばす |
| 拡散 | 一度に扇形に投げる数が1つ増える（Lv1 で2個、Lv2 で3個…。甲羅は0.8倍の大きさ） |
| 貫通 | 甲羅や周回甲羅に当たっても割れずに抜ける回数が1増える |
| 反発 | 甲羅や周回甲羅に当たっても割れずに跳ね返る回数が1増える。跳ね返りは壁での反射と同じに数える（反射回数の上限に数え、分裂・加速もそこで起きる）。ぶつかられた側は通常どおり割れる（相手も反発なら両方跳ね返る）。反発が残っている甲羅は外側に白い輪 |
| 跳弾 | 反射できる回数 +2、寿命 +1.5秒 |
| 加速 | 反射するたびに速さ ×(1 + 0.15×レベル)。最大で元の2倍 |
| 低速化 | 速さ ×0.75（重ねるごとにさらに ×0.75。元の0.3倍まで）。寿命 +2秒、反射できる回数 +1。高速化の逆で、両方付いていれば打ち消し合う。アイコンは前に逆向きの山形 |
| カーブ | 投げた向きから時計回りに曲がり続ける。曲がる速さ 0.9×レベル rad/秒（Lv1 で半径約280px の円）。追尾と両方付いていれば両方かかる。CPU は曲がりを計算に入れて狙う。アイコンは横に弧の矢印 |
| 巨大化 | 大きさ +35%。2レベル以上で重甲羅と同じく、甲羅同士でぶつかると相手だけ割る |
| 高速化 | 速さ +25% |

CPU だけで1試合回すと10ラウンドで決着。1ラウンド43〜116秒で、ほかのモードより長め（手持ちが3つあり、周回甲羅の盾が厚いため）。

### 試合場（セル・オートマトンの洞窟。`src/shell/cave.ts`）

カスタム甲羅だけ、柱の代わりにラウンドごとに作り直す洞窟の試合場で戦う。

- 試合場の内側を40px四方のマス（31×17）に分け、43%のマスをランダムに壁にしてから、「床のマスは周り8マスの壁が5以上なら壁、壁のマスは4以上なら壁のまま」を4回くり返す（外壁の外は床として数える）
- 最初のノイズを点対称にしているので、出来上がりも点対称（4つの出現位置の条件が同じ）
- 出現位置から2マス以内は床。出現位置1からたどれない床は壁で埋め、ほかの出現位置にたどれないときや床の割合が60〜80%に入らないときは作り直す（200通り試して床は63〜80%、中央値76%。1回0.5ms）
- 壁のマスは柱と同じく甲羅を跳ね返し、キャラを通さない。当たり判定は周りのマスだけ調べるので、マスが多くても重くならない
- オンライン対戦では、ホストが地形の種（数値1つ）を配信に載せ、参加者は同じ種から同じ地形を作る

## クラフト（`src/shell/craft.ts`）

カスタム甲羅（甲羅3つ・投げる順番・効果の重ね方）はそのままに、効果の手に入れ方を「ドラフト」から「素材集め」に変えたモード。ラウンドの合間の画面はなく、試合中に甲羅が育つ。

- 試合場に木の箱が12個（点対称）。柱と同じく甲羅を跳ね返し、キャラも通さない。甲羅が1回当たると壊れて、素材が1つ転がり出る
- 壊れた箱は12秒後に同じ場所に戻る（上に誰かいるときは、どくまで待つ）
- 素材は4種類（羽・目玉・石・バネ）。触れると拾う（ボタンは増やさない）
- 拾った素材は今の甲羅（次に投げる甲羅。全部補充中なら順番が一番早い甲羅）に入る。同じ甲羅に素材が2つ揃うと、組み合わせの効果がその場で付き、頭上に「甲羅1 追尾！」と出る
- 入っている素材は画面下の甲羅のカード（「＋？」）と左上の一覧に出る。素材も効果も試合を通して残り、優勝で新しい試合になると空に戻る
- 初めて作った組み合わせは「新レシピ 羽＋目玉＝追尾」と出て、ブラウザに保存される（図鑑の表示は未実装）

| 組み合わせ | 効果 | 組み合わせ | 効果 |
|---|---|---|---|
| 羽＋羽 | 高速化 | 目玉＋目玉 | 追尾×2 |
| 羽＋目玉 | 追尾 | 目玉＋石 | 分裂 |
| 羽＋石 | 貫通 | 目玉＋バネ | 拡散 |
| 羽＋バネ | 加速 | 石＋石 | 巨大化 |
| 石＋バネ | 反発 | バネ＋バネ | 跳弾 |

- CPU は近くに素材が落ちていれば拾いに行き、相手を狙える角度がないときは近くの箱を狙って投げる
- デバッグ（Tab）に「足元に素材を4種類出す」がある
- オンライン対戦には未対応（オンライン対戦ボタンはカスタム甲羅だけに出る）

## ピザの見た目（お試し。今は使っていない。`src/shell/pizza.ts`）

| 追尾 | ブラックオリーブ |

## オンライン対戦（カスタム甲羅）

右上の「オンライン対戦」から、同じ部屋の名前を入れた人どうしで対戦できる（4人まで。空いた席は CPU）。`?r=部屋名` 付きの URL を開くと、その部屋にそのまま入る。

- **ホスト方式**：部屋に一番早く入った人（ホスト）のブラウザがゲームを計算し、状態を約30回/秒で全員に配る。参加者は操作（移動・照準・投げる）を約30回/秒でホストに送り、届いた状態を補間してなめらかに描く
- サーバー（`server/room.ts`、1部屋＝1つの Durable Object）は入退室とホストの管理、メッセージの中継だけをする。ゲームの計算はしない
- 粒子・光・輪などの演出はホストが通知し、参加者が手元で再生する。甲羅の性能は一度だけ送り、以降は番号で参照する
- リプレイは各自の手元の録画（届いた状態）から作る。自分がやられたときのリプレイは、やられた本人だけに流れる
- ドラフトは脱落した順に各自が自分の画面で選ぶ。結果画面の「次へ」はホストだけが押せる
- 参加者が抜けると、その席は CPU が引き継ぐ。ホストが抜けると試合は終わり、残った人の中で次に早く入った人が新しいホストになる
- 対戦中に入った人は観戦になり、次の試合から参加する
- オンライン中はポーズ・早送り・デバッグウィンドウは使えない
- 何も送らない接続は10分で切断する（Durable Object の稼働時間を使い続けないように）

### 無料枠の目安

Workers 無料プランで動く。料金に効くのは部屋（Durable Object）が受け取るメッセージ数（20通で1リクエスト、1日10万リクエストまで）。4人で遊ぶと、ホストの配信30回/秒＋参加者3人の操作30回/秒×3で120通/秒＝6リクエスト/秒になり、1日約4.5時間が目安。超える日が多いなら Workers 有料プラン（月5ドル）にするか、`ShellScene.ts` の `SNAP_HZ` を下げる。

### 未対応・今後

- 参加者の手元での先読み（自分の移動をすぐ反映する）は未実装。参加者は操作から反映まで通信の往復ぶん遅れる
- 実際の別端末・別回線での対戦は未確認（ローカルの2タブで、入室・開始・操作・決着・リプレイ通知・ドラフト・ホスト離脱を確認）

## ローグライク：検証したい3点と、そのための仕掛け

| 確認したいこと | 仕掛け |
| --- | --- |
| ① 撃つだけで楽しいか | 初期状態でも弾は壁で1回反射する。能力なしで遊んで判断する |
| ② 能力取得で明確に楽しくなるか | Tab のデバッグパネルで能力を1つだけ上げ、遊び方の変化を比べる |
| ③ 組み合わせが面白いか | 1回の射撃（分裂した子弾を含む）で3体以上倒すと「N CHAIN」表示。死亡時に最大チェイン・最大同時弾数を表示 |

親弾は水色、反射分裂の子弾は緑、命中拡散の破片は黄で、順に小さい。

## 能力（`src/abilities.ts`）

| 能力 | 最大Lv | 効果 |
| --- | --- | --- |
| 弾数増加 | 2 | 1way → 2way → 3way |
| 巨大化 | 3 | 弾の半径 ×1.4 → ×2.2 |
| 高速化 | 3 | 弾速 ×1.25 → ×1.75（撃った後の弾にも即反映） |
| 跳弾強化 | 3 | 反射回数 1 → 4回 |
| 射程延長 | 3 | 弾の寿命 1.0秒 → 1.5 → 2.1 → 2.8秒。寿命の終わりが近づくと弾が小さく薄くなる |
| 貫通 | 3 | 1体 → 2体 → 3体 |
| ホーミング | 3 | 射程内の最寄りの敵へ旋回（貫通済みの敵は狙わない） |
| 反射分裂 | 3 | 親弾が反射するたびに、小さな子弾（緑）を1発左右交互に飛ばす。1発あたり最大 1 / 2 / 3 回 |
| 連射速度 | 3 | 毎秒 5発 → 6 → 8 → 10発 |
| 命中拡散 | 3 | 親弾が敵に当たると、その位置から小さな破片（黄）が 2 / 3 / 4 発放射状に飛ぶ。破片は0.45秒で消え、それ以上増えない |
| 反射チャージ | 3 | 壁で反射するたびに威力 +0.5 / +1 / +1.5。威力が上がった弾は大きく見える |
| 誘爆 | 3 | 倒した敵が半径 30 / 40 / 50（＋敵の大きさ）で爆発。威力0.5なので雑魚（HP1）は爆発2回で倒れる。爆発で倒れた敵がさらに爆発できるのは Lv2 で1段、Lv3 で2段まで（Lv1 は連鎖なし） |

子弾は分裂も反射もせず、1.2秒で消える。そのため弾数は掛け算ではなく足し算で増え、1射あたり最大 `way数 × (1 + 分裂回数)` 発（全能力最大で12発。命中拡散の破片は別）。分裂回数は実質 `min(反射回数, 分裂上限)` なので、跳弾強化と組み合わせると子弾が増える。弾数の上限は 10000 発（`src/config.ts` の `LIMITS`）。

## 敵（`src/config.ts`）

- 雑魚（赤）: HP1。最初から出る
- 速い雑魚（橙）: HP1・高速。30秒以降
- 硬い敵（紫）: HP8・低速。60秒以降
- 出現位置はランダム（プレイヤーから220px以上離す）。0.7秒前に赤い輪で予告。時間とともに出現間隔が縮み、HPが増える（整数に丸める。雑魚は45秒あたりからHP2）
- 敵はプレイヤーへまっすぐ近づくだけ。接触でHP−1（5で死亡）、1秒無敵
