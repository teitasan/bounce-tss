# 反射弾TSS（プロトタイプ）

2D トップダウンのツインスティックシューター。画面上部のボタンで4つのモードを切り替える（選んだモードはブラウザに保存。初めて開いたときはカスタム甲羅）。

- **ローグライク**: 雑魚を倒して弾を育てる。ローカル・シングルプレイ
- **甲羅バトル**: 元のコンセプト「マリオカートの緑甲羅を投げ合う」の検証用。最終目標は人間同士の対戦で、今は CPU 3体を相手にする
- **カード甲羅**: 甲羅バトルにデッキを足したもの。ラウンドの合間に甲羅の種類を入れ替えてデッキを育てる
- **カスタム甲羅**: 甲羅は常に3つ。ラウンドの合間に効果を付けて、3つの甲羅それぞれを育てる

```bash
cd tss
npm install
npm run dev   # http://localhost:5173
```

## ローグライクの操作

- WASD 移動 / マウス 照準 / 左クリック または Space（長押しで連射）射撃
- Esc ポーズ / Tab デバッグパネル / 死亡後 R でリスタート
- レベルアップ時はクリックか 1・2・3 キーで選択

## 甲羅バトル（`src/shell/`）

### 操作

WASD 移動 / マウス 照準 / 左クリック・Space 甲羅を投げる / Esc ポーズ / R 次のラウンド（自分が脱落した後も可）

### ルール

- 4人のバトルロイヤル。HP3、最後の1人が勝ち。勝利数をラウンドをまたいで数える
- 手持ちの甲羅（最大2個）は自分の周りを回る（マリオカート方式）。投げると1個減り、2.5秒ごとに1個戻る
- 周回している甲羅にも当たり判定がある
  - 飛んできた甲羅に当たると両方割れる（盾）。重甲羅が周回しているときは相手の甲羅だけが割れ、貫通甲羅は1回だけ抜けてくる
  - 相手の体に当たると、相手にダメージを与えて自分の周回甲羅が割れる（体当たり）
  - 周回甲羅同士がぶつかると両方割れる
  - 投げてから0.3秒は、投げた甲羅が自分の周回甲羅を通り抜ける
- 盾は確実ではない。真横から飛んできた甲羅を止められた割合は、手持ち1個で約15%、2個で約35%（周回の位置しだい）
- 緑甲羅は外壁と柱で反射し、4回を超えて反射するか6秒たつと割れる（最後の1.5秒は点滅）
- 甲羅は誰にでも当たる。自分の甲羅も、投げてから0.3秒たつと自分に当たる
- 甲羅同士がぶつかると両方割れる（撃ち落とせる）
- キャラが甲羅に当たる判定は半径11で、見た目（半径14）より少し小さい（かすっても当たらない。`SHELL.hurtRadius`）
- 被弾するとノックバックし、1.2秒無敵
- 軌道ガイドは出さない。飛んでいる甲羅には残像が付く（`ShellScene.ts` の `TRAIL_LENGTH`）

### 見た目と演出（甲羅バトル・カード甲羅・カスタム甲羅で共通。`src/shell/visuals.ts`）

- 甲羅は付いている効果で模様が変わる（追尾＝目玉、分裂＝V字、貫通＝トゲ、反発＝外側の輪、巨大化＝太い縁、加速＝後ろに山形、高速化＝後ろに流線、跳弾＝内側の点、3連＝小さな円3つ）。相手の周りを回る甲羅を見れば効果が分かる。左上と画面下のアイコンも同じ模様
- 壁や柱で跳ねた瞬間、壁沿いに光が走る。甲羅・残像・粒子・壁の縁は加算合成で光る
- 被弾すると一瞬時間が止まり（自分は0.11秒、CPU は0.05秒）、頭上からハートが飛び散る。自分の被弾は画面の縁が赤く光り、左上のカードが揺れてハートが割れる。脱落するとキャラが砕ける
- 追尾甲羅に狙われているキャラの周りに、回る赤い照準が出る（追尾をやめると消える）
- ラウンド開始は「ROUND N」と全員のビルドを見せながら 3・2・1（2.4秒）
- リプレイ：脱落の約1秒前から0.4秒後までを、0.7倍速（約2秒）で拡大して流す。カメラはやられた側と当てた側の両方が入るように追いかけ、2人が近いほど大きく寄る（1.1〜2.1倍、自滅なら1人だけ）（上下の HUD の帯を黒帯で覆い、試合場は端まで見えるようにする。「REPLAY」表示。R かクリックで飛ばせる）。直近4秒ぶんを常に録画している（`ShellScene.ts` の `REPLAY`）
  - 自分が脱落したとき：0.4秒後に、やられた場面を流す。裏では試合が進み続ける（人間同士の対戦で、やられた人だけが見る形を想定）
  - 決着したとき：最後の脱落を流す。自分の脱落で決着した場合や、自分のリプレイ中に決着した場合は、自分のリプレイだけを流す
- リプレイの後、勝者にカメラが寄ってスローモーションになり、0.8秒後に結果を出す。優勝すると最終ビルドを表示して紙吹雪
- 画面の上下に帯を空け、試合場はその間に収める。上の帯にプレイヤーカード（名前・HP・勝ち数の星・甲羅のアイコン）、下の帯に手元の甲羅（補充中はアイコンの周りの輪が溜まっていく）。モード切替は左下
- ドラフトでは CPU が0.55秒ずつ順番に選び、取ったカードに名前が付く。候補を選ぶと、付けた後の甲羅の姿が先に見える

### CPU

- 一番近い相手に対して、適度な距離を保って横に回り込む
- 0.7秒先までに自分の近くを通る甲羅があれば、その進路から横へ逃げる
- 投げるときは96方向の軌道を試し、反射込みで一番早く相手に届く角度を選ぶ（自分に跳ね返る角度は避ける）。照準には少しぶれがある
- 投げる間隔は1.5〜3秒（`SHELL.botThrowInterval`）
- 周回甲羅を入れた後、カード甲羅で CPU 3体だけで5ラウンド回すと1ラウンド34〜63秒、3人が残っている間のフィールドの甲羅は平均5.0個（分裂の子を含む）

### 数値

`src/shell/ShellScene.ts` の `SHELL`（甲羅の速さ・大きさ・寿命・反射回数・同時数・無敵時間など）と、`src/shell/arena.ts` の `PILLARS`（柱の配置）。

## カード甲羅（`src/shell/cards.ts`）

甲羅バトルと同じルールで、甲羅の種類が順番に変わる。デッキはラウンドの合間に育てる（ドラフト）。

### 試合とドラフト

- デッキは緑甲羅6枚から始まり、枚数は試合中ずっと6枚のまま。先に5勝した人が優勝。優勝が決まると全員のデッキと勝利数が初期状態に戻る
- 各ラウンドの後、プレイヤー数ぶん（4枚）の候補をランダムに並べ、脱落した順に選ぶ（最後まで残った勝者が最後）
- 自分の番では「候補1枚とデッキの1枚を交換」か「交換しない」を選ぶ。前の人が取った候補は選べない
  - 1・2・3・4 キーかクリックで候補を選び、続けてデッキの中の入れ替えるカードをクリック
  - N キーか「交換しない」ボタンで交換しない
- 自分より前の CPU が何を取ったかは画面に出る
- 全員のデッキの中身は左上の色の並びで見える
- CPU は、デッキに緑甲羅があれば残っている候補からランダムに取って緑甲羅と入れ替える。緑甲羅がなければ、半々で交換しないか、一番多い種類と入れ替える
- 自分が脱落した後は R で4倍速の早送り（勝敗がドラフトに関わるので、ラウンドは飛ばせない）

### 甲羅の出方


- テトリス方式：投げられるのは「今」の甲羅だけで、次に来る甲羅が3個見える（画面下）。投げるとすぐ次の甲羅になる
- 自分のデッキをシャッフルして順に出し、尽きたらまたシャッフルする
- 周回している手持ちの甲羅が「今」と「次」の甲羅になる（色と大きさで分かる）。同じ1投から出た親子の甲羅は互いにぶつからない
- `cards.ts` の `CARD_RULE.pick` を `true` にすると手札方式に戻る（手札3枚から 1・2・3・Q・E・ホイールで選び、使ったカードは0.6秒で補充）

速さは `cards.ts` の `SPEED_SCALE`（0.8）をかけた後の値。

| 甲羅 | 速さ | 大きさ | 反射 | 寿命 | 特徴 |
| --- | --- | --- | --- | --- | --- |
| 緑甲羅 | 320 | 9 | 4回 | 6秒 | 標準 |
| 跳ね甲羅 | 240 | 8 | 9回 | 9秒 | 遅いが長く残る |
| 分裂甲羅 | 304 | 9 | 3回 | 6秒 | 最初の反射で、跳ね返った方向の左右（±29°）に子甲羅を1つずつ飛ばす。親はそのまま普通に反射して進む。子は小さく明るい色で、1回反射・3秒。分裂前は「V」の印、分裂時に輪が広がる |
| 追尾甲羅 | 272 | 9 | 3回 | 6秒 | 投げた瞬間から、投げた人以外の一番近いキャラへ曲がる。相手まで110px以内に近づくと、その後は曲がらない |
| 重甲羅 | 208 | 15 | 2回 | 6秒 | 甲羅同士でぶつかると相手だけ割る。当たったときのノックバックが1.6倍 |
| 3連甲羅 | 256 | 7 | 2回 | 5秒 | 3方向（約16°間隔）に同時に投げる。手持ちは1個しか減らない（ローグライクの弾数増加） |
| 高速甲羅 | 480 | 8 | 2回 | 4秒 | 速いがすぐ割れる（高速化） |
| 貫通甲羅 | 288 | 9 | 3回 | 6秒 | 甲羅や周回甲羅に1回当たっても割れずに抜ける（貫通） |
| 加速甲羅 | 208 | 9 | 4回 | 7秒 | 反射するたびに1.2倍速くなる。最大で元の2倍（反射チャージ） |

CPU は今の甲羅で当たる角度があれば投げる。追尾甲羅だけは、当たる角度がなくても相手の方へ投げる（手札方式のときは、直接当てられるなら重甲羅・緑甲羅、反射が必要なら分裂・跳ね甲羅、角度がなければ追尾甲羅を優先して選ぶ）。CPU 3体だけで5ラウンド回すと1ラウンド34〜54秒だった。

## カスタム甲羅（`src/shell/custom.ts`）

甲羅バトルと同じルールで、甲羅は常に3つ（甲羅1〜3）。試合開始時は甲羅2だけ追尾1、甲羅1・3は緑甲羅と同じで、ラウンドの合間に効果を付けて育てる。試合の流れ（先に5勝、脱落した順に選ぶ）はカード甲羅と同じ。

- 3つの甲羅が自分の周りを回り、甲羅ごとに補充される（投げた甲羅、または周回中に割れた甲羅だけが2.5秒の補充待ちになる）
- 投げる順番は最初 1→2→3、3つ投げ終えるたびにシャッフル。順番の来た甲羅が補充中なら、手元にある甲羅のうち順番が一番早いものを投げる
- 画面下に3つの甲羅が投げる順に並び、付いている効果が出る。甲羅の色は一番レベルの高い効果の色
- ドラフト：プレイヤー数ぶん（4つ）の効果を、9種類からランダムに候補に並べ、脱落した順に「効果を1つ取って甲羅1〜3のどれかに付ける」か「付けない」を選ぶ。同じ効果を重ねるとレベルが上がる（上限なし）
- 左上に全員の甲羅3つの色が出る（マウスを乗せると効果の一覧）
- CPU は残っている候補からランダムに取り、半分は同じ効果を持つ甲羅に重ね、残りはランダムな甲羅に付ける
- Tab でデバッグウィンドウ：自分の甲羅1〜3に効果を＋／−で好きなだけ積める（すぐ反映。投げた後の甲羅は変わらない）。「自分は無敵」「CPU が投げない」「当たり判定を表示」（赤＝キャラが甲羅に当たる判定、灰＝キャラの見た目、黄＝甲羅）の切り替えと、試合開始時の状態に戻す「全部リセット」付き

| 効果 | 1レベルごとの効果 |
| --- | --- |
| 追尾 | 投げた瞬間から、投げた人以外の一番近いキャラへ曲がる。相手まで110px以内に近づくと、その後は曲がらない。曲がる力はレベルと同じ（1 / 2 / 3 … rad/秒） |
| 分裂 | 最初の n 回の反射で、左右に子甲羅を1つずつ飛ばす |
| 3連 | 一度に投げる数が1つ増える（甲羅は0.8倍の大きさ） |
| 貫通 | 甲羅や周回甲羅に当たっても割れずに抜ける回数が1増える |
| 反発 | 甲羅や周回甲羅に当たっても割れずに跳ね返る回数が1増える。跳ね返りは壁での反射と同じに数える（反射回数の上限に数え、分裂・加速もそこで起きる）。ぶつかられた側は通常どおり割れる（相手も反発なら両方跳ね返る）。反発が残っている甲羅は外側に白い輪 |
| 跳弾 | 反射できる回数 +2、寿命 +1.5秒 |
| 加速 | 反射するたびに速さ ×(1 + 0.15×レベル)。最大で元の2倍 |
| 巨大化 | 大きさ +35%。2レベル以上で重甲羅と同じく、甲羅同士でぶつかると相手だけ割る |
| 高速化 | 速さ +25% |

CPU だけで1試合回すと10ラウンドで決着。1ラウンド43〜116秒で、ほかのモードより長め（手持ちが3つあり、周回甲羅の盾が厚いため）。

## ローグライク：検証したい3点と、そのための仕掛け

| 確認したいこと | 仕掛け |
| --- | --- |
| ① 撃つだけで楽しいか | 初期状態でも弾は壁で1回反射する。能力なしで遊んで判断する |
| ② 能力取得で明確に楽しくなるか | Tab のデバッグパネルで能力を1つだけ上げ、遊び方の変化を比べる |
| ③ 組み合わせが面白いか | 1回の射撃（分裂した子弾を含む）で3体以上倒すと「N CHAIN」表示。死亡時に最大チェイン・最大同時弾数を表示 |

親弾は水色、反射分裂の子弾は緑、命中拡散の破片は黄で、順に小さい。

## 能力（`src/abilities.ts`）

| 能力 | 最大Lv | 効果 |
| --- | --- | --- |
| 弾数増加 | 2 | 1way → 2way → 3way |
| 巨大化 | 3 | 弾の半径 ×1.4 → ×2.2 |
| 高速化 | 3 | 弾速 ×1.25 → ×1.75（撃った後の弾にも即反映） |
| 跳弾強化 | 3 | 反射回数 1 → 4回 |
| 射程延長 | 3 | 弾の寿命 1.0秒 → 1.5 → 2.1 → 2.8秒。寿命の終わりが近づくと弾が小さく薄くなる |
| 貫通 | 3 | 1体 → 2体 → 3体 |
| ホーミング | 3 | 射程内の最寄りの敵へ旋回（貫通済みの敵は狙わない） |
| 反射分裂 | 3 | 親弾が反射するたびに、小さな子弾（緑）を1発左右交互に飛ばす。1発あたり最大 1 / 2 / 3 回 |
| 連射速度 | 3 | 毎秒 5発 → 6 → 8 → 10発 |
| 命中拡散 | 3 | 親弾が敵に当たると、その位置から小さな破片（黄）が 2 / 3 / 4 発放射状に飛ぶ。破片は0.45秒で消え、それ以上増えない |
| 反射チャージ | 3 | 壁で反射するたびに威力 +0.5 / +1 / +1.5。威力が上がった弾は大きく見える |
| 誘爆 | 3 | 倒した敵が半径 30 / 40 / 50（＋敵の大きさ）で爆発。威力0.5なので雑魚（HP1）は爆発2回で倒れる。爆発で倒れた敵がさらに爆発できるのは Lv2 で1段、Lv3 で2段まで（Lv1 は連鎖なし） |

子弾は分裂も反射もせず、1.2秒で消える。そのため弾数は掛け算ではなく足し算で増え、1射あたり最大 `way数 × (1 + 分裂回数)` 発（全能力最大で12発。命中拡散の破片は別）。分裂回数は実質 `min(反射回数, 分裂上限)` なので、跳弾強化と組み合わせると子弾が増える。弾数の上限は 10000 発（`src/config.ts` の `LIMITS`）。

## 敵（`src/config.ts`）

- 雑魚（赤）: HP1。最初から出る
- 速い雑魚（橙）: HP1・高速。30秒以降
- 硬い敵（紫）: HP8・低速。60秒以降
- 出現位置はランダム（プレイヤーから220px以上離す）。0.7秒前に赤い輪で予告。時間とともに出現間隔が縮み、HPが増える（整数に丸める。雑魚は45秒あたりからHP2）
- 敵はプレイヤーへまっすぐ近づくだけ。接触でHP−1（5で死亡）、1秒無敵

## 構成

```text
src/main.ts         Phaser 起動
src/GameScene.ts    ゲーム本体（移動・射撃・反射・分裂・敵・レベルアップ・描画）
src/abilities.ts    能力定義とレベル → 弾性能の換算
src/config.ts       マップ・プレイヤー・敵・出現ペースの数値
src/ui.ts           DOM の HUD・レベルアップ選択・ゲームオーバー・デバッグパネル
src/shell/arena.ts  甲羅バトルのマップ（柱）、甲羅の反射移動、壁・柱からの押し出し
src/shell/ShellScene.ts  甲羅バトル本体（3モード共通。CPU の判断とドラフトを含む）
src/shell/cards.ts  甲羅の種類、カード甲羅のデッキとドラフト候補
src/shell/custom.ts カスタム甲羅の効果、レベルから甲羅の性能を作る処理、投げる順番
src/shell/visuals.ts 甲羅の見た目（効果ごとの模様。ゲーム画面用と HUD の SVG アイコン）
```

物理エンジンは使わず、弾の反射と当たり判定は自前（高速弾のすり抜け防止に 8px 刻みで判定）。描画はすべて Graphics の図形。
